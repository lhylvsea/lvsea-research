# 来源与证据

## 来源等级

来源等级不是事实真伪的自动判定，而是决定审查强度和结论语气。

| 等级 | 典型来源 | 使用方式 |
| --- | --- | --- |
| A | 官方原始文件、监管/统计数据、原始论文、标准原文、当事人一手记录 | 可支撑关键事实，仍检查范围和日期 |
| B | 同行评审论文、公开数据集、行业标准解读、编辑审核的权威报道 | 可支撑机制和交叉核验 |
| C | 可追溯的内部记录、结构化访谈、现场数据、专家判断 | 明确样本和局限后使用 |
| D | 类比、模型建议、常识、未经验证的推测 | 只能作为假设或检索线索 |
| E | 营销文案、匿名说法、搜索摘要、无出处社交贴文 | 不作为核心证据 |

“来源等级高”不等于“支持的主张就正确”。还要检查来源是否直接谈论该主张、是否过时、是否有利益冲突和是否与其他来源独立。

## 证据账本

每条重要主张都写成一行：

| 字段 | 内容 |
| --- | --- |
| claim | 可被证伪的主张，而不是泛泛评价 |
| status | 已核验事实／来源解释／本次推断／合理假设／尚未核验 |
| source | 直接页面或文件 URL |
| source_date | 来源发布日期或数据时间 |
| accessed_at | 实际访问日期 |
| grade | A–E |
| supports | 支持、削弱或仅提供背景 |
| independence | 独立、部分重叠、同源或未知 |
| limits | 口径、样本、地域、时效、利益冲突和遗漏 |

搜索结果页、聚合摘要和转载文章用于发现线索，不直接当作原始证据。关键数字必须回到原表、原文、原始公告或可核对的直接页面。

## 反证与独立性

每个核心结论至少主动寻找一种可能推翻它的材料：

- 失败案例或相反结果；
- 同期但不同地区/规模的样本；
- 对立观点或用户投诉；
- 反事实：如果关键原因不成立，哪些事实仍能解释结果；
- 机制替代：是否有更简单的解释。

同一新闻稿被多个网站转载不算多源。多个来源来自同一数据库、同一机构或同一受访者时，降低独立性并避免重复计权。

## 结论语气

- 事实：资料显示……
- 证据支持的推断：基于这些来源，更合理的解释是……
- 暂定判断：在当前信息下，我暂时判断……
- 未核验：目前找到的材料不足以确认……
- 证据冲突：来源 A 与来源 B 在……上冲突，不能合并成单一确定结论。
