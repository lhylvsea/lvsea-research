# 研究操作系统

## Intent 简报

开始前形成一页简报：

- 研究对象与对象类型；
- 用户真正要回答的问题；
- 时间点、地域、行业或材料范围；
- 研究用途：了解、决策、汇报、写作、设计、改造或谈判；
- 期望产物与长度；
- 已知材料与约束；
- 不应做的事情；
- 风险级别和需要人工复核的部分。

如果用户只说“研究一下”，先给出低成本默认范围：对象定义、发展/机制、当前状态、替代方案、关键风险和来源清单。

## 查询矩阵

按对象和目的选择查询线，不机械全跑：

| 信息线 | 典型问题 |
| --- | --- |
| 定义 | 它是什么，不是什么，边界在哪里 |
| 起源与演进 | 何时出现，关键节点，为什么转向 |
| 机制与结构 | 输入、过程、输出、约束和反馈是什么 |
| 当前状态 | 最新版本、规则、价格、性能或组织现状 |
| 比较与替代 | 用户实际会把它和什么比较 |
| 反证与失败 | 什么情况下不成立，失败者怎么说 |
| 一手来源 | 官方文件、原始论文、公告、数据、原始访谈 |
| 用户情境 | 对当前企业、岗位、设备或目标的具体影响 |

深研时可把信息线分给独立检索任务，但每条线都要回填统一证据账本，不能把并行数量当作质量。

## 阶段门

1. 范围门：对象和问题可识别，时间/地域边界已记录。
2. 覆盖门：定义、核心机制、当前状态和至少一条反面证据已覆盖。
3. 核验门：关键数字/日期/因果至少有直接来源或明确标为待核验。
4. 解释门：主结论能从证据账本追溯，不是凭风格生成。
5. 行动门：建议有成本、可逆性、负责人或下一条信息路径。
6. 交付门：链接、引用、限制、格式和未验证项已核对。

## 什么时候提问

只在答案会因以下差异而改变时提问：

- 研究对象有多个同名实体；
- 用户要的是信息解释还是现实决策；
- 研究范围改变来源和结论；
- 输出格式有硬性要求；
- 风险授权不清。

问题最多 1–3 个，优先问能最大幅度减少不确定性的那几个。
